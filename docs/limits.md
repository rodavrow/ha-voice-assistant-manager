# Limits

Part of the Voice Assistant Manager documentation. Back to the [README](../README.md).

- **Sentence-trigger automations bypass the assistant.** Home Assistant runs automations with a sentence trigger before any conversation agent is asked.
- **Voice triggers handled on the satellite itself bypass it too**, if your satellite firmware has them.
- **Typed requests go by the logged-in user, not the voice.** Anyone using a phone that is logged in as Person 1 is treated as Person 1. This holds even when the request names a satellite: its helper is never used for a request that carries a Home Assistant user. If no users are chosen, these requests count as Person 1 unless you change "A device without speaker recognition is".
- **Another integration that calls the conversation API with a satellite's device and no user is judged by that satellite's helper**, like a voice request. Home Assistant's own pipelines are the usual case, but this holds for any caller.
- **Calling the main agent directly skips the assistant entirely.** Only requests sent to an assistant go through it.
- **An assistant whose settings were never saved refuses typed requests from the phone app and the browser.** Such an assistant still asks the older "who is speaking" script, which only learns the device, so it cannot tell who is logged in. Save the settings (or run the setup guide) to use the phone app and the browser with it. Voice requests from satellites keep using the script.
- **VoIP phones count as a device without speaker recognition.** A call through Home Assistant's VoIP integration runs as a hidden system user that cannot be chosen under People, so "A device without speaker recognition is" decides who is calling, whether or not users are chosen. The same goes for any other system user, such as an add-on. A satellite's helper is never used for these requests.
- **Two people and strangers.** There are exactly two personas.
- **Voice Assistant Manager does not choose which assistants are live on a satellite.** That is a setting of the satellite. See [More assistants than wake-word slots](multiple-assistants.md).
- **An older "who is speaking" script that does not say who is speaking is trusted.** When the script's answer has a `who` that is not `owner` or `wife`, and neither fixed replies nor a reply agent, the request is refused with "Sorry, I can't help you." and the main agent is never asked. An answer without `who` still goes to the main agent with the persona text the script gave, as it always did: only the script knows who it meant. Saved settings do not have this limit.
- **If the assistant cannot work out who is speaking, it refuses.** When the lookup fails, when an assistant whose settings were never saved has no "who is speaking" script, or when that script fails or answers with nothing, the reply is "Sorry, I can't help you." and the main agent is never asked.
- **Some agents must have no tools, and they are checked on every use.** These are the agent that writes refusals, the memory agent and the announcement agent. Each must exist, and may not be Home Assistant's own agent, an assistant of this integration, or the main agent of one. It may not be able to control the home either. The assistant judges that only from what the agent's integration reports, so an agent whose integration does not report it is trusted: give these agents no tools yourself. An agent with no state in Home Assistant (it is missing, or it is an old-style id that is not an entity) is refused. The check runs when the settings are saved and again before each use, so an agent that gains tools later is caught. See [An agent was refused](troubleshooting.md#an-agent-was-refused).
- **Built-in commands wait for the voice match** and are answered with a spoken reply, where Home Assistant on its own may only play a short acknowledge sound.
- **Only voice assistant pipelines that use one of the assistants are covered.** Any other Home Assistant voice assistant you have set up is unaffected.
- **Memory costs a second model call.** With memory on, the memory agent is called after each conversational turn (not for built-in commands or very short requests). That adds cost, not waiting time. With "Save important facts without being asked" off it is only called for remember and forget requests.
- **Remembered facts are only as good as the memory agent's judgement.** It can save something trivial, miss something important or word a fact wrongly. Check the lists now and then under Configure > Memory.
- **Private relies on the memory agent.** It has to notice that the person asked to keep something private. If it misses that, the fact is shared. Check the list, or add the fact yourself with `(private)` in front. Anyone who can open the assistant's Configure dialog can read every list, private facts included.
- **A shared satellite has a shared history.** Within one ongoing conversation the main agent also sees what was said earlier in it, whoever said it. Private only governs what is brought back from memory later.
- **A spoken false confirmation cannot always be taken back.** The assistant corrects the reply it hands back and the history. If your voice pipeline streams a reply to the speaker while it is still being written, some or all of it may already have been spoken.
- **The false-confirmation check needs to see the tool calls.** It works when the main agent writes its tool calls to the conversation's history, as Home Assistant's LLM agents do in a voice pipeline. With an agent that does not, the assistant leaves replies alone and relies on the prompt rules.
- **Reminder wording is recognised in English.** "Remind me…", "set a reminder…" and times such as "at 5 pm" or "in an hour" are matched in English when deciding what to keep out of memory and what counts as a confirmation.
- **The announcement keeps the reminder intact only as well as its agent does.** It is told to keep every detail, and an empty or over-long line is dropped, but the wording is not checked word for word. Use plain text if a reminder must be exact.
- **Calendar events are told apart by their title and times.** Home Assistant's `calendar.get_events` does not give an event's id. An event whose title or times change is announced again, and two events in one calendar with the same title and times are announced once.
- **A calendar announcement is not checked word for word.** The agent that writes it is told to keep what the event is and when, and an empty or over-long line is dropped, but it can still word something wrongly. Your script always gets the untouched title as well.
- **A calendar event is announced at one moment only.** There is no second reminder for the same event.
- **Remember and forget requests are recognised in English.** With auto-save off, a request in another language is not picked up.
- **The settings page shows one entry in the sidebar for all users who are administrators.** Hiding it hides it for everyone. Each user can still hide or reorder sidebar entries for themselves in their Home Assistant profile.
- English is the only translation of the settings screen and the settings page.
- **The quick path for favorites is English only.** "Play Radio 2" is recognised in English, and only as the whole request. In another language, or with other words around it, the request goes on as any other request: to the built-in commands (when they are on) and then the main agent.
- **Favorites need the tools switched on for the main agent.** Saving, forgetting and any play request the quick path does not catch are done by the main agent, which only knows them when the Voice Assistant Manager tools are switched on for it next to Assist. See [Favorites](favorites.md#switch-the-tools-on-for-the-main-agent).
- **Who is speaking, for the tools, lasts one turn.** The assistant notes who asked while it waits for the main agent, and forgets it when the answer is given, or after a minute at most. A tool called later, for example from an automation, is refused.
- **Saving by name needs Music Assistant,** and "save this" only saves a station or a stream, not a song or an episode. "Save this" always needs a name from you ("save this as Radio 2"); without one, the assistant asks for it.
- **A favorite whose speaker cannot be worked out goes to the main agent.** When the quick path finds the favorite but not the speaker (none named and the satellite has none, or the name matches no player or several), the built-in commands are skipped and the main agent answers. It can ask which speaker you mean.
- **A chat show is only as safe as its announcement agents.** Voice Assistant Manager refuses an agent that can control the home, and the lines are only spoken, never carried out. They can still be wrong or rude.
- **A chat show runs one at a time and is not kept.** It ends when Home Assistant restarts or one of the two assistants is reloaded.
- **Joining in needs a satellite.** On a media player the chat is listen-only. "Listen after each round" is best effort.
